# Halloween Git Rescue

## 1. Presentació i entorn

Aquest projecte consisteix en una pràctica de control de versions amb Git, ambientada en un incident fictici de seguretat informàtica durant la nit de Halloween.

L'objectiu principal és reconstruir un repositori, gestionar diferents branques de desenvolupament, resoldre conflictes de fusió i eliminar codi defectuós mitjançant les eines de Git.
